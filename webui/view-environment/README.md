Guest environment view in the VM inspector’s Environment tab.

- Lists plain values and secret aliases in a table with per-variable edit and delete actions.
- Adds several variables together; quick actions merge into the latest VM configuration and reject stale edits.
- Retains the bulk environment editor for create/edit VM drafts.
- Preserves other VM configuration fields and requires a stopped VM.
- Explains that guest environment secrets are visible inside the guest, unlike proxy-injected credentials.
