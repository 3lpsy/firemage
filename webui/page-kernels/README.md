# page-kernels

Kernel directory inventory at `#kernels` in the desktop sidebar.

- Lists server-installed files and aliases, with local search and refresh.
- Administrators upload binaries, import HTTPS downloads with optional SHA-256 verification, and edit aliases.
- Add kernel requires an alias and saves it with the uploaded or downloaded kernel.
- Alias and download guidance lives beside field labels; catalog refresh uses an icon.
- Deletion removes the file and is disabled while a VM references it.
