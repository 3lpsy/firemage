Boot input view in the VM inspector’s Boot tab.

- Uploads or pastes boot file contents as text or base64 copies, never host shares.
- Configures guest destinations with inline removal; UID/GID and octal permissions share one row.
- Edits the userdata script run after guest setup with the shared shell-highlighted textarea.
- Preserves other VM definition fields and requires a stopped VM.
- Library assets share the create/edit VM attachment picker and preserve stable asset references.
