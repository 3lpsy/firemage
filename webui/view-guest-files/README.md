Shared stopped-VM Files view for the VM sidebar and full page.

- Browses the root disk through inode-based directory requests; expanded folders load on demand.
- Shows breadcrumbs, ownership, modes and escaped control characters in filenames.
- Downloads bounded regular files directly with same-origin authentication; symlinks and special files are not downloadable.
- Collapses the directory tree behind a button in narrow containers. Active VMs do not mount the browser.
